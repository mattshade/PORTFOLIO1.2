# Visual language

**Architectural blueprint identity** — technical precision, high-contrast type, and a single lime accent system shared across the portfolio and this Storybook.

## Design tokens

**Source of truth:** all tokens live on `:root` in `src/index.css` (imported by the app and Storybook preview). Components and stories should read these **CSS variables**—not one-off hex values—so color, type, elevation, and glass treatments stay consistent.

| Token | Role |
| --- | --- |
| `--bg` | Page background |
| `--bg-elevated` | Raised surfaces |
| `--bg-glass` | Glass panels (`backdrop-filter` companions) |
| `--border` | Default hairline dividers |
| `--border-strong` | Emphasized edges / inputs |
| `--text` | Primary copy |
| `--text-muted` | Secondary / meta text |
| `--brand` | Brand mark (same hue family as accent) |
| `--accent` | Links, focus, primary CTAs |
| `--accent-secondary` | Secondary emphasis (amber) |
| `--hover` / `--accent-hover` | Hover / pressed link & control states |
| `--accent-dim` | Soft glows and text-shadow on hover |
| `--grid-color` | Blueprint grid lines (with `--bg`) |
| `--shadow-sm` | Small elevation |
| `--shadow-md` | Deeper elevation |
| `--shadow-glass` | Floating glass cards |
| `--font-sans` | UI and body (Geist stack) |
| `--font-mono` | Code and technical labels (Geist Mono stack) |

Structural spacing (e.g. `main` offset for the fixed nav, `scroll-margin` on section anchors) is also defined in that stylesheet so scroll and layout behave the same in production and in Storybook.

## Structural principles

- **Grid-first:** content aligns to a **40px** blueprint grid (see **Foundations → Layout & grid**).
- **Micro-interactions:** hover uses `cubic-bezier` easing and restrained scale—not novelty for its own sake.
- **Glass:** `.glass` / `.glass-strong` compose tokens with shared blur and radii—see `src/index.css`.

## Storybook setup

- **Router:** `.storybook/preview.ts` wraps every story in `MemoryRouter` so `Link` / `useLocation` work (`Resume`, `Nav`, etc.).
- **Static assets:** `.storybook/main.ts` maps `public/` so `/images/…` and other static files resolve in stories.
