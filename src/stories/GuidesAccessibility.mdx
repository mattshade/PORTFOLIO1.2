# Accessibility

## In Storybook

- The **Accessibility** addon runs against each story. Treat **serious** violations as merge blockers; **moderate** issues need a ticket or fix before release.
- Use the **viewport** toolbar to confirm tap targets and reading order on narrow widths.

## Product rules

- **Focus:** interactive elements must show visible focus; accent color is available for focus rings where components define them.
- **Images:** project and hero imagery use `alt=""` when decorative; meaningful thumbnails include descriptive `alt` in data when added.
- **Motion:** the global `OrigamiAviaryBackground` canvas is `aria-hidden` and must not convey unique information; respect `prefers-reduced-motion`.
- **Modals:** project detail sets `role="dialog"`, locks body scroll, and exposes a close control.

## Color

- Primary reading pairs **`--text` on `--bg`** — lime accent is for links and emphasis, not long-form body text at small sizes.
- When proposing new surfaces, check **contrast** against WCAG AA for text and interactive states.
